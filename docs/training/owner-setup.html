Initialize the empty training database

Training only. This does not enable /training. No live data is copied. The script stops if the database name or owner is wrong, or if any user table already exists. It creates the current application tables plus training-only state, outbox, audit, and installation tables, but no employees, cards, or transactions.

  1. In Neon, select your confirmed Legend Bucks Training project.
  2. Open SQL Editor. Select database legend_bucks_training and role legend_bucks_training_owner.
  3. Copy the complete script below, paste it into the editor, and run it once.
  4. Tell Replit Agent “Training tables created”, or share the error message without credentials.

Keep Replit’s TRAINING_DATABASE_URL set to legend_training_app. Do not replace it with the owner connection. Do not change DATABASE_URL, run Neon link/deploy/MCP, or enable training.

-- OWNER ACTION: run only in the NEW, EMPTY legend_bucks_training database.
-- This creates structure from source code. It does not copy any live data.
-- Do not register this file with live migrations, publish hooks or app startup.
BEGIN;
SET LOCAL search_path = public, pg_catalog;
SELECT pg_advisory_xact_lock(768135091);
DO $guard$
BEGIN
  IF current_database() <> 'legend_bucks_training'
     OR current_user <> 'legend_bucks_training_owner' THEN
    RAISE EXCEPTION 'Refusing setup: wrong database or owner.';
  END IF;
  IF EXISTS (
    SELECT 1 FROM pg_catalog.pg_tables
    WHERE schemaname NOT IN ('pg_catalog', 'information_schema')
  ) THEN
    RAISE EXCEPTION 'Refusing setup: database is not empty. Nothing will be erased.';
  END IF;
  IF NOT EXISTS (
    SELECT 1 FROM pg_catalog.pg_roles
    WHERE rolname = 'legend_training_app' AND rolcanlogin
      AND NOT (rolsuper OR rolcreatedb OR rolcreaterole OR rolreplication OR rolbypassrls)
  ) OR pg_has_role('legend_training_app', 'neon_superuser', 'MEMBER') THEN
    RAISE EXCEPTION 'Refusing setup: restricted training login is missing or elevated.';
  END IF;
END
$guard$;
